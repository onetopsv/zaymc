Java Đạo

PC / Mac / Linux
  • 1

    Khai mở Minecraft Java Edition

    Khởi động Minecraft phiên bản 1.12 - 1.21+ trên linh bảo của đạo hữu.

  • 2

    Nhập Multiplayer → Add Server

    Nhấn "Multiplayer", sau đó chọn "Add Server" để tạo liên kết tiên môn mới.

  • 3

    Khắc Tiên Môn Lệnh

    Điền zaymc.vel-go.fun:25360 vào ô "Server Address" rồi nhấn Done.

  • 4

    Đạp Kiếm Nhập Môn!

    Double-click vào tiên môn vừa khắc để kết nối. Chúc đạo hữu hành trình hanh thông!
