Quản trị bí điển ZAYMC

Nhập thông tin kho GitHub của web một lần. Trang này chỉ lưu trong trình duyệt của đạo hữu, không gửi đi đâu ngoài GitHub.

Tạo token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Chọn Only select repositories (chỉ kho của web này), mục Permissions → Contents: Read and write. Token này chính là chìa khóa: ai không có nó thì không sửa được web.
